# 架构师面试题 —— 中间件、存储与技术判断

> 重点考察：是否只停留在"使用层面"，还是深入到原理、选型权衡与二次开发/排障深度。

---

## 一、中间件原理与深度

### 消息队列

1. Kafka/RocketMQ/RabbitMQ 深度对比：
   - 架构模型差异（推 vs 拉、NameServer vs ZK/KRaft）？
   - 事务消息、延迟消息、顺序消息，三家的支持程度和实现原理？
   - 如果让你为交易主链路选型，决策矩阵怎么列？
2. Kafka 无 ZK 化（KRaft）解决了什么问题？为什么能提升扩展性？
3. 罗列 MQ 在你们系统的所有使用场景，然后回答：哪些场景其实不该用 MQ（被滥用的地方）？
4. MQ 集群出现堆积 5000 万条，给出完整的应急处置 SOP 和根因分析框架。

### RPC 与注册中心

5. Dubbo3 的应用级服务发现解决了什么问题（与接口级的对比）？百万实例场景下注册中心压力怎么算？
6. 注册中心的健康检查机制（心跳/ TTL / 连接状态）的误判场景？服务下线后的流量残留怎么处理？
7. RPC 泛化调用、异步调用、隐式传参的实现原理？你们有没有二次封装过 RPC 框架，做了什么增强？

### 网关与流量

8. Nginx/OpenResty 的 worker 模型、upstream 机制、动态 upstream 怎么实现？
9. 自研网关 vs 开源网关（Spring Cloud Gateway / APISIX / Kong）的选型论证？APISIX 的 etcd + 动态路由优势在哪？
10. 网关作为全局单点的容量计算：连接数、带宽、TLS 握手开销怎么估？

## 二、存储选型与架构

### 关系型数据库

11. MySQL 深度：
    - InnoDB 的 MVCC 实现链路（ReadView + undo log），RR 与 RC 的差异本质？
    - redo log 与 binlog 的两阶段提交为什么必须有？组提交机制讲一下？
    - 主从延迟的根因分类与治理手段？并行复制原理？
    - 大表 DDL 的方案对比（pt-osc / gh-ost / MySQL 8.0 instant DDL）？
12. 分库分表中间件（ShardingSphere / 自研 proxy）原理：SQL 解析改写、结果归并、分布式 ID 的坑？

### NoSQL 与新型存储

13. Redis 架构深水区：
    - 主从复制全量/增量的流程，replication backlog 溢出后会怎样？
    - Cluster 的 gossip 协议、哈希槽迁移过程，迁移期间的双写请求怎么处理？
    - 单线程为什么快？6.0 多线程改了什么、没改什么？
    - 你做过哪些 Redis 大规模治理（实例数、内存、慢查询、热点）？量化讲。
14. Elasticsearch：
    - 写入链路（refresh/translog/merge）与近实时原理？
    - 深分页问题（from+size / search_after / scroll）的取舍？
    - 分片数怎么定？reindex 数据迁移怎么做？
15. HBase/Cassandra 列存的适用场景？LSM-Tree 的写放大/读放大怎么权衡，compaction 策略？
16. ClickHouse/Doris 等 OLAP：大数据量多维分析的选型对比？Join 能力、更新能力的局限？
17. TiDB 等 NewSQL：什么场景值得引入？与"MySQL 分库分表 + 中间件"路线的对比论证？
18. 对象存储（S3/OSS）在业务架构里的典型用法？元数据管理与海量小文件的坑？

## 三、技术判断与选型

19. 描述一次你"顶住压力否决了一个流行技术方案"的经历。论证过程是什么？
20. 引入一个新中间件的标准评估清单你会列哪些（功能、性能、可靠性、运维、社区、退出成本……）？退出成本（迁移通道）为什么重要？
21. 你们技术栈里最"老"的组件是什么？怎么评估要不要升级？升级策略（灰度/双跑/回滚）怎么定？
22. 自研 vs 开源 vs 商业采购的决策框架？举一个你做错过的选型，代价是什么，学到了什么？
23. 技术债怎么管理：技术债的识别、登记、偿还排期的机制你怎么搭？业务没空还债怎么办？
24. 面对一个"花哨但你不熟悉的新技术"（如某新型数据库），你的学习与评估路径是什么？怎么避免拍脑袋下结论？
