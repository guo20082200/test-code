# 架构师面试题 —— 分布式、一致性与高可用

> 重点考察：一致性理论功底、容灾设计思路、稳定性体系是否真正落地过。

---

## 一、分布式理论

1. CAP 与 BASE 在你负责的系统里是怎么体现的？举一个你亲手做过的"牺牲 C 保 A"的例子。
2. Paxos/Raft 你了解多少？Raft 的选举、日志复制、成员变更讲一遍。如果面试官说"你们用的组件底层不是 Raft"，你怎么回答为什么还需要懂它？
3. 脑裂是什么？你们系统里有哪些防脑裂机制（quorum、fencing token、仲裁节点）？
4. 分布式系统里"时间是不可靠的"：NTP 跳变、物理时钟漂移会引发什么问题？你用过/了解哪些规避手段（逻辑时钟、HLC、TrueTime）？
5. 幂等设计的所有手段盘点：唯一索引、状态机、token 机制、乐观锁……各自的适用边界？写接口幂等你的标准做法是什么？
6. 分布式锁的 N 种实现对比（Redis/Redisson/Redlock/ZK/etcd/DB）。如果有人说"我们所有场景都用 Redis 分布式锁"，你会给他什么建议？

## 二、数据一致性与事务

7. 你做过的一致性要求最高的系统是什么？从"业务不接受不一致"到"最终一致兜底"是怎么和业务方达成共识的？
8. 对账系统怎么设计？
   - 准实时对账 vs T+1 对账的架构差异？
   - 差异数据的处理流程（自动修复/人工工单）？
   - 对账本身出错怎么办（对账系统的对账）？
9. 可靠消息最终一致的完整链路：生产端确认、存储、投递重试、消费幂等、死信、补偿，每一环的失败场景你都想清楚了吗？
10. Seata 的 AT 模式原理（全局锁、undo_log、二阶段异步提交）？什么场景不能用 AT？
11. 跨库分页、跨库 JOIN、跨库事务——分库分表后这三座大山分别怎么处理？让你现在重新设计，会先做哪一步？

## 三、高可用与容灾

12. 你负责的系统现在全挂了，写一份故障预案文档的目录结构。
13. 多机房/异地多活：
    - 同城双活、两地三中心、异地多活（单元化）三种方案的架构差异与成本？
    - 单元化路由：按用户维度怎么分片？流量怎么导到正确单元？
    - 数据跨机房同步的延迟与冲突处理？切机房时怎么保证不丢数据（RPO=0 吗）？
    - 机房级演练（切流）你们做过吗？切流步骤和回切条件？
14. 稳定性体系落地：
    - 限流：单机限流 vs 集群限流怎么实现？压测容量怎么定限流阈值？
    - 熔断：熔断策略（错误率/慢调用比例/异常数）怎么选？半开状态的并发探测怎么控制？
    - 降级：降级开关的管理（配置中心 + 审批）、降级预案分级（L1/L2/L3）怎么设计？
    - 隔离：线程池隔离 vs 信号量隔离 vs 集群隔离，各自的坑？
15. 依赖治理：怎么画出系统的依赖拓扑？强弱依赖怎么识别和治理？循环依赖怎么解？
16. 容量规划：大促容量怎么算？从 QPS 推导到机器数的完整链条（QPS → 线程数 → CPU → 实例数 → DB 容量 → 带宽），漏了哪环会翻车？
17. 混沌工程：故障注入你们演练过什么场景？怎么防止演练事故影响线上？
18. RTO/RPO 你们的目标值是多少？怎么验证达标的？

## 四、数据层架构

19. 分库分表：
    - 分片键怎么选？如果核心查询不带分片键怎么办（基因法/异构索引/宽表）？
    - 扩容方案：翻倍扩容 vs 一致性哈希 vs 成倍迁移，数据迁移停机窗口怎么做？
    - 什么情况下你建议不加分库分表，先用其他手段（读写分离/归档/列存）？
20. 冷热数据分离与归档：归档策略、归档后查询怎么路由、归档数据回查怎么设计？
21. 慢查询治理体系化：慢 SQL 发现 → 治理 → 防劣化（上线前 SQL 审核门禁）的闭环怎么做？
22. 缓存架构的顶层设计：多级缓存的失效策略、缓存命中率下降的排查思路、缓存层的容量规划？
