# 高级 Java 工程师面试题 —— 框架、数据库、中间件与工程实战

> 适用岗位：高级 Java 开发工程师（3~8 年）。与《05-Java核心与并发》配套使用，重点看「是否只停留在会用」。

---

## 一、Spring 与主流框架（15 分钟）

1. Spring Bean 生命周期追问链：
   - 从实例化到销毁的完整流程（实例化 → 属性填充 → Aware → BeanPostProcessor 前后置 → init → 使用 → 销毁）；
   - 三级缓存解决循环依赖的过程讲一遍；为什么是三级而不是两级？什么循环依赖依然解决不了（构造器注入、prototype）？
2. BeanFactory 与 FactoryBean 的区别？`getObject` 什么时候被调用，举例（MyBatis Mapper / Feign Client）说明框架怎么利用它。
3. Spring 事务失效的 N 种场景（必考）：自调用、非 public、异常被 catch、rollbackFor 配置、传播行为配错、多线程调用……你踩过哪个坑，怎么发现的？
4. 事务传播行为：`REQUIRED` / `REQUIRES_NEW` / `NESTED` 的区别与实际场景；`REQUIRES_NEW` 挂起外层事务的底层动作是什么？
5. Spring MVC 请求处理流程；`HandlerInterceptor` 与 `Filter` 的区别与执行顺序。
6. Spring Boot 自动装配原理：`@EnableAutoConfiguration` → `spring.factories`/`AutoConfiguration.imports` → 条件注解；自己写过 starter 吗，说下结构？
7. Spring Cloud 核心组件在你们项目里怎么组合的（注册发现、配置、网关、熔断）？注册中心换成 Nacos 后 Eureka 的自我保护机制你还了解吗？
8. MyBatis：`#{}` 与 `${}` 本质区别；一级/二级缓存的作用域与生产建议；插件（拦截器）原理，你用插件做过什么（分页/慢 SQL 打印/数据脱敏）？

## 二、MySQL 与数据访问（15 分钟）

9. 索引追问链：
   - B+ 树为什么不用 B 树/红黑树/哈希？树高怎么算（2000 万数据约 3 层）？
   - 聚簇索引 vs 二级索引、回表、覆盖索引、索引下推（ICP）；
   - 最左前缀原则、联合索引列顺序怎么定（区分度 + 排序 + 覆盖）；
   - 给一条慢 SQL，你说说分析路径（explain 的 type/key/rows/extra 逐项解读）。
10. 事务与锁：
    - MVCC 的 ReadView 判断规则，RC 与 RR 的生成时机差异；
    - 行锁、间隙锁、临键锁分别什么时候加？RR 下 `update ... where name=非索引列` 会锁什么？
    - 死锁案例：你说一个实际遇到的死锁，怎么通过 `show engine innodb status` 定位，怎么解？
11. 主从延迟：产生原因（单线程回放/大事务/机器差）与治理（并行复制、半同步、读写分离路由策略、强制走主）？
12. 大表优化路线图：2000 万行的表查询变慢，从索引 → 读写分离 → 分库分表 → 归档的演进顺序和判断依据。
13. 场景题：一个商品列表页要求「多条件筛选 + 排序 + 分页」，DB 方案怎么做？什么信号出现时你会引入 ES？

## 三、Redis 与缓存（10 分钟）

14. 五种基础数据结构与底层编码（SDS、ziplist/listpack、skiplist）；ZSet 的跳表为什么不用红黑树（范围查询 + 实现复杂度）？
15. 过期删除策略（惰性 + 定期）与内存淘汰策略（8 种，LRU/LFU 的近似实现）；主从、持久化期间的删除行为。
16. 缓存穿透/击穿/雪崩 + 缓存与 DB 一致性（先更新 DB 再删缓存、延迟双删）——不仅要会背，追问：为什么是删缓存而不是更新缓存？
17. 分布式锁追问链：SET NX PX + 唯一值 + Lua 释放的完整代码逻辑；Redisson 看门狗原理；主从切换导致锁丢失的场景与缓解方案。
18. 场景题：
    - 用 Redis 实现一个「近 7 天连续签到」功能，用什么结构，存储量怎么算（BitMap）？
    - 排行榜实时更新 Top 100，怎么设计（ZSet + 分数设计）？
    - 统计一个页面UV，1 亿数据怎么权衡精度与内存（HyperLogLog）？

## 四、分布式基础（10 分钟，高级岗够用即可）

19. CAP/BASE 用自己的话讲，配一个你项目里的例子（讲不出例子的视为背书）。
20. 接口幂等的实现手段盘点 + 你在项目里落地的具体方案（token、唯一索引、状态机，选其一说细节）。
21. 分布式 ID 方案对比：UUID、雪花、号段、Redis；雪花时钟回拨问题怎么处理？
22. 分布式锁的合理使用边界：哪些场景其实该用 DB 唯一约束/乐观锁而不是分布式锁？
23. MQ 基础：为什么不丢消息（生产端 confirm/broker 刷盘/消费端手动 ack）？重复消费怎么处理？顺序消息怎么保证？——三个问题各给你在用的 MQ 举一例。

## 五、工程实战与排查（15 分钟，重点区分「真做过」）

24. 线上排查组合拳（口述 SOP）：
    - 接口偶发超时：trace 定位 → 线程池/GC/下游逐层排除的顺序；
    - `jstack` 里出现大量 `WAITING (on object monitor)` 与大量 `TIMED_WAITING (parking)` 分别意味着什么？
    - 数据库连接池打满的表现、定位与止损；
    - 一个接口 RT 从 50ms 涨到 500ms 的完整排查树（画出你的决策路径）。
25. 日志与监控：你们的日志规范（traceId 透传、脱敏、分级）；核心接口的监控指标你定义哪些（RT 分位数、QPS、错误率、依赖健康度）？告警阈值怎么定避免误报？
26. 单元测试与代码质量：写不写单测、怎么写（Mock 边界在哪）、覆盖率是否设门禁；一个好 Bug 报告/一个难查的偶现 Bug 的定位过程举例。
27. 设计模式实战：说一个你项目里真正用设计模式解决了实际问题的例子（策略/模板/责任链/状态机），不谈概念谈收益；如果是为了模式而模式，请直说。
28. 场景题：上游接口每天偶发返回脏数据导致下游故障，你的系统性解法（契约测试、防御性校验、隔离层、告警、追溯）？
29. 场景题：让你从 0 接手一个新系统，你怎么在两周内建立对它的掌控（文档、链路梳理、依赖拓扑、监控盲区、风险清单）？

## 六、编码题（可选，25 分钟）

30. 手写：用 `CompletableFuture` 并行调用 3 个下游（各有超时与降级），任一失败不影响其他，汇总返回——写出线程池注入与超时控制的正确用法。
31. 手写：从 1 亿个 URL 中判断某个 URL 是否存在，内存限制 1GB——布隆过滤器的手写思路 + 误判率讨论。
32. 手写：多线程统计一个 10GB 文件里每个单词的出现次数（文件切分 → 分片统计 → 合并），考察 ForkJoin/线程池划分与并发汇总。

## 附：高级工程师评估要点

| 维度 | 权重 | 观察点 |
|---|---|---|
| Java 核心与并发 | 30% | 追问链第二层是否还能接住（原理层而非概念层） |
| 框架原理 | 15% | 是否踩过坑并知道为什么（事务失效、循环依赖等） |
| 数据库/缓存 | 25% | 索引与锁的实战分析能力，缓存方案的权衡 |
| 分布式基础 | 15% | 能结合自己项目讲，而非纯背概念 |
| 工程排查与编码 | 15% | 有排查 SOP、有真实案例、编码题基本功 |

**判定要点**：
- **中级（未达标）**：概念能背，追问「为什么」超过两层就断；案例模糊、无数据。
- **高级（达标）**：原理讲到机制层，有真实踩坑与排查案例，能给出方案权衡。
- **资深（超出）**：能反客为主，主动指出题目场景中的隐藏前提与更好的问法；编码题考虑边界与并发正确性。
