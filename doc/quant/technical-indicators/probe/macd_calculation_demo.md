# MACD 计算过程演示

本文基于真实数据 [msft_1day_macd.json](./msft_1day_macd.json)（Twelve Data API，`MSFT` / `1day` / `12, 26, 9`），演示 MACD 三个输出值 `macd`、`macd_signal`、`macd_hist` 是如何一步步计算出来的。

> 注意：该 JSON 文件只包含指标结果，不含原始收盘价。因此 MACD 线本身（EMA12 − EMA26）用示意例子演示机制；信号线与柱状图则用文件中的真实数据逐日验证，结果可与 API 返回值精确对上。

## 1. 计算公式总览

MACD = Moving Average Convergence Divergence（指数平滑异同移动平均线），基于**收盘价**计算，共三条线：

| 名称 | 字段 | 公式 |
|---|---|---|
| MACD 线（DIF） | `macd` | `EMA(close, 12) − EMA(close, 26)` |
| 信号线（DEA） | `macd_signal` | `EMA(macd, 9)` |
| 柱状图（MACD 柱） | `macd_hist` | `macd − macd_signal` |

其中 EMA（指数移动平均）的递推公式为：

```
EMA_today = EMA_yesterday + k × (price_today − EMA_yesterday)

平滑系数 k = 2 / (N + 1)
```

三个周期对应的平滑系数：

- 快线 `N=12`：`k = 2/13 ≈ 0.1538`
- 慢线 `N=26`：`k = 2/27 ≈ 0.0370`
- 信号线 `N=9`：`k = 2/10 = 0.2`

## 2. EMA 的计算机制（示意例子）

EMA 是递推定义的，起点（种子值）通常取前 N 个价格的**简单平均（SMA）**，之后逐日递推。

以 `N=3`、收盘价 `[10, 11, 12, 13, 14]` 为例，`k = 2/(3+1) = 0.5`：

```
第 3 天（种子）: EMA = SMA(10, 11, 12) = 11.000
第 4 天: EMA = 11.0 + 0.5 × (13 − 11.0) = 12.000
第 5 天: EMA = 12.0 + 0.5 × (14 − 12.0) = 13.000
```

可见 EMA 对新价格的响应速度由 k 决定：周期越长，k 越小，曲线越平滑、越滞后。

**预热期**：MACD 线要用到 EMA26，所以最早也要有 26 根 K 线之后才能产出第一个 MACD 值。Twelve Data 在服务端基于完整历史计算，`outputsize=50` 只是返回最近 50 个结果（本文件为 2026-08-28 至 2026-11-06），每个返回值都已经是"预热完成"的状态。

## 3. MACD 线：EMA12 − EMA26（机制演示）

对每个交易日 t：

```
macd[t] = EMA12(close)[t] − EMA26(close)[t]

EMA12(close)[t] = EMA12(close)[t−1] + 0.1538 × (close[t] − EMA12(close)[t−1])
EMA26(close)[t] = EMA26(close)[t−1] + 0.0370 × (close[t] − EMA26(close)[t−1])
```

直觉：快 EMA 贴近近期价格，慢 EMA 反映更长期的趋势。

- 股价**加速上涨**时，EMA12 甩开 EMA26，MACD 线上升（本文件 9 月中旬 MACD 一路冲到 18+，对应一轮强势上涨）；
- 股价**回落/转弱**时，EMA12 掉头向下向 EMA26 靠拢甚至反超，MACD 线下降（本文件 11 月初 MACD 从 18 一路跌到 2~4）。

> 由于文件中不含收盘价，此处无法用真实数字复算 EMA12/EMA26；第 4、5 节用文件内的真实值验证信号线和柱状图。

## 4. 信号线：对 MACD 线再做 9 日 EMA（真实数据验证）

用 `k = 2/(9+1) = 0.2` 对 `macd` 列递推。文件数据按日期倒序，以下为正序计算：

**2026-11-02 → 2026-11-03：**

```
signal[11-03] = 6.17570 + 0.2 × (2.18395 − 6.17570)
              = 6.17570 + 0.2 × (−3.99175)
              = 6.17570 − 0.79835
              = 5.37735     ← 与 API 返回值 5.37735 完全一致 ✓
```

**2026-11-03 → 2026-11-04：**

```
signal[11-04] = 5.37735 + 0.2 × (4.51327 − 5.37735)
              = 5.37735 + 0.2 × (−0.86408)
              = 5.20453     ← 与 API 返回值 5.20453 完全一致 ✓
```

**2026-11-04 → 2026-11-05：**

```
signal[11-05] = 5.20453 + 0.2 × (4.70173 − 5.20453)
              = 5.20453 − 0.10056
              = 5.10397     ← 与 API 返回值 5.10397 完全一致 ✓
```

**2026-11-05 → 2026-11-06：**

```
signal[11-06] = 5.10397 + 0.2 × (4.37142 − 5.10397)
              = 5.10397 − 0.14651
              = 4.95746     ← 与 API 返回值 4.95746 完全一致 ✓
```

## 5. 柱状图：MACD 线减信号线（真实数据验证）

```
macd_hist = macd − macd_signal
```

| 日期 | macd | macd_signal | 计算 | API 返回 `macd_hist` | 一致 |
|---|---|---|---|---|---|
| 2026-11-06 | 4.37142 | 4.95746 | 4.37142 − 4.95746 = −0.58604 | −0.58604549 | ✓ |
| 2026-11-03 | 2.18395 | 5.37735 | 2.18395 − 5.37735 = −3.19340 | −3.19340 | ✓ |
| 2026-10-13 | 12.35046 | 10.16570 | 12.35046 − 10.16570 = 2.18476 | 2.18476 | ✓ |

（部分行的 API 值保留了更高精度，如 `−0.58604549`，差值在第 5 位小数以后，为四舍五入误差。）

## 6. 完整计算流水线

```
收盘价 close[]
   │
   ├──> EMA(close, 12)  ─┐
   │                     ├──> macd = EMA12 − EMA26 ──> EMA(macd, 9) = macd_signal
   └──> EMA(close, 26) ──┘                                    │
                                                              └──> macd_hist = macd − macd_signal
```

三个输出全部串起来了：柱状图本质上衡量的是"MACD 线与其自身 9 日 EMA 的偏离程度"，即动量的动量。

## 7. 结合数据解读

- **金叉**（`macd_hist` 由负转正，即 MACD 线上穿信号线）：`2026-09-30`（−0.0474）→ `2026-10-01`（+0.0601），随后一路走强至 10 月中旬。
- **死叉**（`macd_hist` 由正转负，即 MACD 线下穿信号线）：`2026-10-16`（+0.2880）→ `2026-10-19`（−0.1535），此后柱状图持续为负且 11 月初迅速放大（11-02 达 −3.45），对应一轮明显的下跌动量。
- 柱状图的**收敛/发散**也有意义：`11-03` 至 `11-06` 柱状图从 −3.19 收窄到 −0.59，说明下跌动量在减弱。
