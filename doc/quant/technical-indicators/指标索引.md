## 01 重叠研究（Overlap Studies，21 个）

> 叠加在价格主图上使用，用于平滑价格、界定趋势与支撑阻力。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/sma` | 简单移动平均线 | 最近 N 周期价格的算术平均，最基础的趋势平滑线，用于判断趋势方向、动态支撑/阻力，常作为金叉/死叉的信号基准。`High demand` | [sma.md](01-overlap-studies/sma.md) |
| `/ema` | 指数移动平均线 | 对近期价格赋予更高权重的指数平滑均线，比 SMA 反应更快、滞后更小，也是 MACD、PPO 等指标的基础组件。`High demand` | [ema.md](01-overlap-studies/ema.md) |
| `/wma` | 加权移动平均线 | 按线性权重加权（越近的价格权重越大）的均线，灵敏度介于 SMA 与 EMA 之间。 | [wma.md](01-overlap-studies/wma.md) |
| `/dema` | 双指数移动平均线 | `2×EMA − EMA(EMA)`，通过二次平滑消除 EMA 的滞后，更贴近价格、转向更早。 | [dema.md](01-overlap-studies/dema.md) |
| `/tema` | 三重指数移动平均线 | `3×EMA − 3×EMA(EMA) + EMA(EMA(EMA))`，三重平滑后进一步降低滞后，适合快速趋势跟踪。 | [tema.md](01-overlap-studies/tema.md) |
| `/t3ma` | T3 移动平均线 | Tillson T3，多次 EMA 平滑叠加体积因子（vfactor）调节，在平滑性与灵敏度之间取得平衡，滞后极小。（注：源文件标题误译为"三重指数移动平均线"，与 TEMA 非同一算法） | [t3ma.md](01-overlap-studies/t3ma.md) |
| `/trima` | 三角移动平均线 | 对价格做两次等权平均（SMA 的 SMA），权重呈三角形分布，去噪能力强但滞后较大，适合过滤震荡行情。 | [trima.md](01-overlap-studies/trima.md) |
| `/kama` | 考夫曼自适应移动平均线 | 依据"市场效率系数"自适应调节平滑速度：趋势行情紧跟价格、震荡行情自动放平过滤噪音。 | [kama.md](01-overlap-studies/kama.md) |
| `/mama` | MESA 自适应移动平均线 | 基于 Hilbert 变换测量主导周期，输出快（MAMA）、慢（FAIMA）两条自适应均线，适合周期性明显的市场。 | [mama.md](01-overlap-studies/mama.md) |
| `/ma` | 移动平均线 | 通用均线端点，通过 `ma_type` 参数在 SMA/EMA/WMA/DEMA/TEMA/TRIMA/KAMA/MAMA/T3 之间切换。 | [ma.md](01-overlap-studies/ma.md) |
| `/bbands` | 布林带 | 中轨为 SMA，上下轨为中轨 ± N 倍标准差的波动通道；用于识别超买/超卖、波动挤压与扩张、均值回归。`High demand` | [bbands.md](01-overlap-studies/bbands.md) |
| `/keltner` | 肯特纳通道 | 中轨为 EMA、上下轨按 ATR 倍数偏移的通道；与布林带类似但对极端值更稳健，常用于趋势突破与移动止损。 | [keltner.md](01-overlap-studies/keltner.md) |
| `/sar` | 抛物线止损与反转 | 递推生成的抛物线形跟踪止损曲线，价格与 SAR 交叉即视为趋势反转，直接给出趋势方向与止损位。 | [sar.md](01-overlap-studies/sar.md) |
| `/sarext` | 抛物线止损与反转扩展版 | SAR 的扩展版，额外暴露初始化方式、加速因子递增/最大值等参数，可精细控制止损曲线行为。 | [sarext.md](01-overlap-studies/sarext.md) |
| `/ichimoku` | 一目均衡表 | 转换线、基准线、先行带 A/B、滞后带五线一体的综合趋势系统，一站式判断趋势、支撑阻力与买卖时机。 | [ichimoku.md](01-overlap-studies/ichimoku.md) |
| `/ht_trendline` | 希尔伯特变换瞬时趋势线 | 对价格做 Hilbert 变换得到的瞬时趋势平滑线，去噪的同时几乎无滞后，末端值相当于即时趋势信号。 | [ht_trendline.md](01-overlap-studies/ht_trendline.md) |
| `/mcginley_dynamic` | 麦吉利动态指标 | 按价格相对均线的偏离自动调节跟踪速度的均线，快速行情中能避免频繁假穿越，被视为"自动避震"的均线。 | [mcginley_dynamic.md](01-overlap-studies/mcginley_dynamic.md) |
| `/vwap` | 成交量加权平均价 | 累计成交额 ÷ 累计成交量，机构常用的公允价格基准与日内多空分界线，高于 VWAP 偏多、低于偏空。 | [vwap.md](01-overlap-studies/vwap.md) |
| `/midpoint` | 中点价 | 区间内（最高价 + 最低价）/ 2 的移动序列，粗略反映价格区间中枢。 | [midpoint.md](01-overlap-studies/midpoint.md) |
| `/midprice` | 中间价 | 当前 K 线（最高价 + 最低价）/ 2，不做区间平均，用于快速中枢参考与通道计算。 | [midprice.md](01-overlap-studies/midprice.md) |
| `/pivot_points_hl` | 枢轴点高低点 | 基于前一周期高、低、收盘价计算轴心点及多级支撑/阻力位（S1~S3、R1~R3），日内交易定位进出场点位。 | [pivot_points_hl.md](01-overlap-studies/pivot_points_hl.md) |

## 02 动量指标（Momentum Indicators，34 个）

> 副图震荡类指标，衡量价格运动的速度与强度，检测超买/超卖、背离与动量变化。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/rsi` | 相对强弱指标 | 用一段时间内平均涨幅与平均跌幅之比（0~100）衡量买卖力量：>70 超买、<30 超卖，与价格的背离预示反转。`High demand` | [rsi.md](02-momentum-indicators/rsi.md) |
| `/macd` | 指数平滑异同移动平均线 | DIF = EMA12 − EMA26，DEA = EMA(DIF, 9)，柱状图 = DIF − DEA；用金叉/死叉与柱状图伸缩判断趋势动量的转换与衰竭。`High demand` | [macd.md](02-momentum-indicators/macd.md) |
| `/macdext` | MACD 扩展版 | MACD 的可调版本：快线、慢线、信号线的均线类型（SMA/EMA/WMA 等）与周期均可自定义。 | [macdext.md](02-momentum-indicators/macdext.md) |
| `/macd_slope` | MACD 斜率 | MACD 线的斜率序列，量化动量变化的速度，用于提前发现动量增强或衰竭。 | [macd_slope.md](02-momentum-indicators/macd_slope.md) |
| `/stoch` | 随机振荡器（慢速） | %K 衡量收盘价在近期高低区间中的位置，慢速版对 %K 再平滑并输出 %D；超买（>80）/超卖（<20）及 K/D 交叉产生信号。`High demand` | [stoch.md](02-momentum-indicators/stoch.md) |
| `/stochf` | 快速随机振荡器 | STOCH 的快速版，不对 %K 做平滑，信号更灵敏但噪音更多，适合短线配合过滤使用。 | [stochf.md](02-momentum-indicators/stochf.md) |
| `/stochrsi` | 随机相对强弱指标 | 对 RSI 再做随机化处理，将 RSI 放大到 0~100 区间，能放大超买/超卖信号，适合短线择时，但噪音较大。 | [stochrsi.md](02-momentum-indicators/stochrsi.md) |
| `/cci` | 商品通道指数 | 价格偏离其典型价格统计均值的程度；±100 之外视为超买/超卖，也常用于识别新一轮趋势的启动。 | [cci.md](02-momentum-indicators/cci.md) |
| `/willr` | 威廉指标 | 与随机指标同源（-100~0），衡量收盘价在区间的相对位置：-20 以上超买、-80 以下超卖。 | [willr.md](02-momentum-indicators/willr.md) |
| `/mom` | 动量 | `close − N 期前 close`，最直接的动量度量，值过零线指示动量方向转换。 | [mom.md](02-momentum-indicators/mom.md) |
| `/roc` | 变动率 | N 期价格变化率 ×100（`ROC = (close/close[N] − 1) × 100`），衡量涨跌速度。 | [roc.md](02-momentum-indicators/roc.md) |
| `/rocp` | 变动率百分比 | ROC 的小数形式（`close/close[N] − 1`，0.05 即 5%），便于程序化计算。 | [rocp.md](02-momentum-indicators/rocp.md) |
| `/rocr` | 变动率比值 | `close / close[N]` 的比值形式，大于 1 为涨、小于 1 为跌。 | [rocr.md](02-momentum-indicators/rocr.md) |
| `/rocr100` | 变动率比值 100 | `close / close[N] × 100`，以 100 为中轴的比值形式。 | [rocr100.md](02-momentum-indicators/rocr100.md) |
| `/apo` | 绝对价格振荡器 | 快均线与慢均线的绝对差值，类似只有 MACD 线没有信号线，衡量动量的绝对强度。 | [apo.md](02-momentum-indicators/apo.md) |
| `/ppo` | 百分比价格振荡器 | 快慢均线差除以慢均线，以百分比消除价格量纲影响，便于跨标的、跨价格区间比较动量。 | [ppo.md](02-momentum-indicators/ppo.md) |
| `/cmo` | 钱德动量振荡器 | RSI 的变体（-100~100），用上涨总和与下跌总和之比衡量动量，±50 常作超买/超卖阈值。 | [cmo.md](02-momentum-indicators/cmo.md) |
| `/adx` | 平均趋向指数 | 衡量趋势强度（0~100，不含方向）：>25 视为强趋势、<20 视为震荡，常用于趋势策略与震荡策略的切换开关。`High demand` | [adx.md](02-momentum-indicators/adx.md) |
| `/adxr` | 平均趋向指数评级 | 当期 ADX 与 N 期前 ADX 的平均值，对 ADX 再平滑，减少信号抖动，适合确认趋势持续性。 | [adxr.md](02-momentum-indicators/adxr.md) |
| `/dx` | 动向指数 | +DI 与 −DI 的差比（0~100），是 ADX 的原始输入，反映单根周期内多空方向性强度。 | [dx.md](02-momentum-indicators/dx.md) |
| `/plus_di` | 正向指标 | 上升动量占比（0~100），与 −DI 的交叉产生做多/做空趋势信号。 | [plus_di.md](02-momentum-indicators/plus_di.md) |
| `/minus_di` | 负向指标 | 下降动量占比（0~100），与 +DI 的交叉产生趋势信号。 | [minus_di.md](02-momentum-indicators/minus_di.md) |
| `/plus_dm` | 正向变动 | 单向上升波幅（当日 high − 前日 high 与前日 low − 当日 low 取大者），+DI 的计算中间量。 | [plus_dm.md](02-momentum-indicators/plus_dm.md) |
| `/minus_dm` | 负向变动 | 单向下降波幅，−DI 的计算中间量。 | [minus_dm.md](02-momentum-indicators/minus_dm.md) |
| `/aroon` | Aroon 指标 | 分别统计距最近最高价/最低价的时间占比（0~100），两线上穿下穿及 70/30 阈值用于发现新趋势诞生。 | [aroon.md](02-momentum-indicators/aroon.md) |
| `/aroonosc` | Aroon 振荡器 | Aroon Up − Aroon Down（-100~100），正值偏多、负值偏空，是 Aroon 的简化单线形式。 | [aroonosc.md](02-momentum-indicators/aroonosc.md) |
| `/bop` | 多空力量 | `(close − open) / (high − low)` 的均值（-1~1），以 K 线实体占振幅的比例衡量买卖压力强弱。 | [bop.md](02-momentum-indicators/bop.md) |
| `/mfi` | 资金流量指标 | 带成交量的 RSI（0~100）：>80 超买、<20 超卖；用典型价格 × 成交量衡量资金实际流向，比 RSI 多一层量能确认。 | [mfi.md](02-momentum-indicators/mfi.md) |
| `/ultosc` | 终极振荡器 | 融合 7/14/28 三个周期的买入压力加权（0~100），避免单一周期的背离误判；>70 超买、<30 超卖。 | [ultosc.md](02-momentum-indicators/ultosc.md) |
| `/dpo` | 区间震荡线 | 剔除 N/2+1 期趋势项后的价格残差，用于识别周期性高低点，而非判断趋势方向。 | [dpo.md](02-momentum-indicators/dpo.md) |
| `/kst` | 确然信号 | 四组不同周期 ROC（10/15/20/30）加权合成的中长线动量指标，配合信号线交叉判断中期趋势转折。 | [kst.md](02-momentum-indicators/kst.md) |
| `/coppock` | 估波曲线 | 长周期（默认 14/11）ROC 之和的 WMA，长线底部识别指标，由负转正常被视为长期买入信号。 | [coppock.md](02-momentum-indicators/coppock.md) |
| `/crsi` | 康纳斯相对强弱指标 | RSI(3)、随机化 RSI(2)、ROC(100) 排名三者组合的短线超买超卖指标，为高频/短线交易设计。 | [crsi.md](02-momentum-indicators/crsi.md) |
| `/percent_b` | %B 指标 | 布林带位置归一化：`(price − 下轨) / (上轨 − 下轨)`，0 = 下轨、1 = 上轨、>1 或 <0 表示突破轨道。`High demand` | [percent_b.md](02-momentum-indicators/percent_b.md) |

## 03 成交量指标（Volume Indicators，4 个）

> 用成交量确认价格走势的有效性，或提前预警趋势衰竭。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/obv` | 能量潮 (OBV) | 将成交量按涨跌方向累加（涨加、跌减）形成的累积线；OBV 与价格背离（价新高而 OBV 不新高）预示趋势反转。 | [obv.md](03-volume-indicators/obv.md) |
| `/ad` | 累积/派发线 | 按收盘价在 K 线内位置加权（靠近最高价记买入、靠近最低价记卖出）累积成交量，衡量资金进出，背离提示转折。 | [ad.md](03-volume-indicators/ad.md) |
| `/adosc` | 累积/派发线震荡指标 | AD 快慢 EMA（默认 3、10）之差的振荡器，捕捉短期资金流强弱变化。 | [adosc.md](03-volume-indicators/adosc.md) |
| `/rvol` | 相对成交量 | 当期成交量与历史同期平均成交量之比，>2 视为异常放量，用于确认突破有效性或量能枯竭。 | [rvol.md](03-volume-indicators/rvol.md) |

## 04 波动率指标（Volatility Indicators，5 个）

> 量化价格波动幅度，用于风险评估、止损设置与突破识别。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/trange` | 真实波幅 | 当期高低差与前日跳空的最大值（`max(H−L, \|H−prevC\|, \|L−prevC\|)`），是波动率计算的原子量。 | [trange.md](04-volatility-indicators/trange.md) |
| `/atr` | 真实波动幅度均值 | TR 的移动平均（默认 14 期），衡量绝对波动水平；常用于设置止损（如 2×ATR）与仓位管理。 | [atr.md](04-volatility-indicators/atr.md) |
| `/natr` | 归一化真实波动幅度均值 | ATR ÷ 价格 × 100，消除价格量纲后的波动率，可跨标的、跨价格区间直接比较。 | [natr.md](04-volatility-indicators/natr.md) |
| `/supertrend` | 超级趋势线 | 基于 ATR 的自适应跟踪止损带：价格在带上方为多头趋势、下方为空头趋势，方向翻转即趋势翻转信号，直观的趋势跟随指标。 | [supertrend.md](04-volatility-indicators/supertrend.md) |
| `/supertrend_heikinashicandles` | 超级趋势线（Heikin Ashi 版） | 在平均 K 线（Heikin Ashi）上计算的 Supertrend，信号更平滑、假翻转更少。 | [supertrend_heikinashicandles.md](04-volatility-indicators/supertrend_heikinashicandles.md) |

## 05 价格变换（Price Transform，18 个）

> 将原始 OHLC 数据转换为衍生价格序列，或做算术/数学变换，多为其他指标的输入。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/avgprice` | 平均价格 | `(O + H + L + C) / 4`，四价均值，比单一收盘价更均衡地代表当根 K 线价格水平。 | [avgprice.md](05-price-transform/avgprice.md) |
| `/hlc3` | 最高最低收盘价均值 | `(H + L + C) / 3`，常用衍生价格，RSI/CCI 等指标可选的 series_type。 | [hlc3.md](05-price-transform/hlc3.md) |
| `/medprice` | 中间价 | `(H + L) / 2`，当前 K 线最高价与最低价的中值。 | [medprice.md](05-price-transform/medprice.md) |
| `/typprice` | 典型价格 | `(H + L + C) / 3`，CCI 与 MFI 的默认输入价格。 | [typprice.md](05-price-transform/typprice.md) |
| `/wclprice` | 加权收盘价 | `(H + L + 2C) / 4`，收盘价权重加倍的加权价格。 | [wclprice.md](05-price-transform/wclprice.md) |

## 06 周期指标（Cycle Indicators，5 个）

> 基于 Hilbert 变换检测价格行为中的周期性模式，适合震荡/周期市分析。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/ht_dcperiod` | 希尔伯特变换主导周期 | 用 Hilbert 变换估计当前价格的主导周期长度（K 线数），用于确定"当前市场的一个循环大约多少根 K 线"。 | [ht_dcperiod.md](06-cycle-indicators/ht_dcperiod.md) |
| `/ht_dcphase` | 希尔伯特变换主导周期相位 | 当前价格在主导周期中所处的相位角（0°~360°），相位接近转折区提示周期拐点。 | [ht_dcphase.md](06-cycle-indicators/ht_dcphase.md) |
| `/ht_phasor` | 希尔伯特变换相量分量 | 输出同相（in-phase）与正交（quadrature）两个分量，是构造自定义周期指标的原始材料。 | [ht_phasor.md](06-cycle-indicators/ht_phasor.md) |
| `/ht_sine` | 希尔伯特变换正弦波 | 将主导周期映射为正弦线与领先正弦线，两线交叉发生在周期转折点附近，用于周期市的买卖点定位。 | [ht_sine.md](06-cycle-indicators/ht_sine.md) |
| `/ht_trendmode` | 希尔伯特变换趋势/周期模式 | 输出 0（周期模式）或 1（趋势模式），判断当前市场适合用周期策略还是趋势策略。 | [ht_trendmode.md](06-cycle-indicators/ht_trendmode.md) |

## 07 统计函数（Statistic Functions，15 个）

> 对价格序列计算统计度量——离散度、回归、相关性——可独立分析或作为其他模型的输入。

| API 路由 | 指标名称 | 作用说明 | 文档 |
|---|---|---|---|
| `/stddev` | 标准差 | 最近 N 期的滚动标准差，度量价格离散度；布林带轨道宽度的来源，也用于波动率分析。 | [stddev.md](07-statistic-functions/stddev.md) |
| `/var` | 方差 | 最近 N 期的滚动方差（标准差的平方），衡量价格波动幅度。 | [var.md](07-statistic-functions/var.md) |
| `/linearreg` | 线性回归 | 最近 N 期最小二乘回归线的终值，比均线更贴合趋势中枢、滞后更小。 | [linearreg.md](07-statistic-functions/linearreg.md) |
| `/linearregslope` | 线性回归斜率 | 回归线每根 K 线的预期变化量，直接量化趋势速度，正负号指示方向。 | [linearregslope.md](07-statistic-functions/linearregslope.md) |
| `/linearregangle` | 线性回归角度 | 将斜率换算为角度（度），跨市场、跨价格尺度比较趋势陡峭程度。 | [linearregangle.md](07-statistic-functions/linearregangle.md) |
| `/linearregintercept` | 线性回归截距 | 回归线在区间起点的截距值，配合斜率可还原整条趋势线。 | [linearregintercept.md](07-statistic-functions/linearregintercept.md) |
| `/tsf` | 时间序列预测 | 基于线性回归向前外推一期的预测值（回归终值 + 斜率），短周期趋势外推。 | [tsf.md](07-statistic-functions/tsf.md) |
| `/correl` | 相关性 | 两个标的最近 N 期的皮尔逊相关系数（-1~1），衡量联动程度，是组合分散化的依据。 | [correl.md](07-statistic-functions/correl.md) |
| `/beta` | Beta 指标 | 标的相对基准（如大盘指数）的 Beta 值，衡量系统性风险敏感度：Beta>1 波动放大、<1 更抗跌。 | [beta.md](07-statistic-functions/beta.md) |
| `/max` | 最大值 | 最近 N 期的滚动最高值，作为阻力位或突破参照。 | [max.md](07-statistic-functions/max.md) |
| `/min` | 最小值 | 最近 N 期的滚动最低值，作为支撑位或跌破参照。 | [min.md](07-statistic-functions/min.md) |
| `/maxindex` | 最大值索引 | 最近 N 期最高值出现的相对位置（距当前几根 K 线），用于判断新高的"新鲜度"。 | [maxindex.md](07-statistic-functions/maxindex.md) |
| `/minindex` | 最小值索引 | 最近 N 期最低值出现的相对位置。 | [minindex.md](07-statistic-functions/minindex.md) |
| `/minmax` | 最小值和最大值 | 一次调用同时返回滚动最小值与最大值，用于构造价格通道（Donchian 通道类）。 | [minmax.md](07-statistic-functions/minmax.md) |
| `/minmaxindex` | 最小值和最大值索引 | 同时返回滚动最小值与最大值的索引位置。 | [minmaxindex.md](07-statistic-functions/minmaxindex.md) |
