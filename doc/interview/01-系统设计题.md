# 架构师面试题 —— 系统设计（白板题）

> 考察方式：给出开放场景，让候选人现场画图设计，重点看容量估算、边界划分、权衡取舍、故障预案。每题建议 25~40 分钟。

---

## 一、高频经典题

### 1. 设计一个短链接服务（如 t.cn）

- 要求：生成短链、302 跳转、统计点击量，日均 1 亿次跳转。
- 追问：
  - 短码怎么生成？自增 ID + Base62、哈希 + 冲突处理、发号器预分配，各自优缺点？
  - 写多读多？跳转 QPS 估算，单机多少，怎么水平扩展？
  - 重定向用 301 还是 302？各有何副作用？
  - 热点短链怎么扛？缓存淘汰策略、布隆过滤器防穿透？
  - 点击统计是同步记还是异步记？会不会丢？
  - 与第三方对接的防刷、封禁链接怎么设计？

### 2. 设计一个秒杀/抢购系统

- 要求：10 万 QPS 峰值、1000 件库存、防超卖。
- 追问：
  - 流量怎么逐层削减（CDN → 网关限流 → Redis 预扣 → MQ 削峰 → DB）？
  - Redis 扣减用什么保证原子？库存分桶怎么做，分桶带来的"有库存但扣不到"怎么处理？
  - Redis 与 DB 库存不一致怎么办？最终一致性靠什么兜底（对账/补偿）？
  - 黄牛刷单怎么防？一人一单怎么实现（Redis + DB 双重幂等）？
  - 秒杀服务挂了怎么降级？所有预案开关列出来说一遍。

### 3. 设计一个feed 流系统（微博/朋友圈）

- 推模式（写扩散）vs 拉模式（读扩散）vs 混合，怎么选？大 V 百万粉丝怎么办？
- 收件箱/发件箱存储模型怎么设计？存储用什么（Redis ZSet / DB / LSM 系）？
- 分页翻页、取关后动态清理、删除动态怎么同步？
- 冷热数据分层：活跃用户 vs 三个月不登录用户的 feed 怎么存储？
- 推拉结合下，一致性怎么保证（发动态与推送的顺序）？

### 4. 设计一个分布式文件存储（类网盘）

- 文件怎么切分（分块）、去重（哈希）、元数据与数据分离？
- 小文件问题怎么解决？合并存储（Compact）怎么做？
- 副本分布策略（机架感知）、一致性协议怎么选？
- 上传断点续传、秒传（已有文件秒返回）怎么实现？
- 元数据服务的扩展性：按什么分片？元数据迁移怎么办？

### 5. 设计一个 IM 即时通讯系统

- 长连接网关怎么设计？单机百万连接怎么做到（内存、fd、心跳参数）？
- 消息 ID 怎么生成？怎么保证消息不丢、不重、不乱序（单聊/群聊分别讨论）？
- 读扩散 vs 写扩散在群聊里的取舍？万人群怎么办？
- 离线消息、多端同步（sequence 号机制）怎么设计？
- 已读回执、消息撤回、端到端加密要考虑什么？

### 6. 设计一个支付系统 / 账务系统

- 记账模型：复式记账、账户表设计、余额并发扣减怎么防负数（行锁/流水冲正）？
- 账务强一致用什么方案？热点账户（大商户）怎么做缓冲记账/异步记账？
- 对账系统怎么设计：日切、对账文件解析、差异处理（长短款）？
- 幂等、防重放、单笔/批量限额怎么落地？
- 挂账、冲正、退款的边界场景怎么处理？

## 二、进阶场景题

### 7. 设计一个分布式任务调度平台

- 单机定时任务在集群下为什么有问题？分布式调度核心要解决什么（分片、不重不漏、failover）？
- 时间轮原理？海量延迟任务怎么存？
- 任务分片策略、执行节点动态上下线、任务抢占怎么实现？
- 依赖编排（DAG 任务）怎么设计？失败重试、超时控制？
- 与 XXL-Job / Elastic-Job 对比，让你自己设计核心模型怎么画？

### 8. 设计一个配置中心（类 Nacos/Apollo）

- 配置的发布、监听（长轮询 vs 推送）、灰度发布怎么实现？
- 长轮询机制底层原理，客户端与服务端交互时序？
- 配置一致性：多节点配置中心数据同步怎么保证？
- 客户端容灾：配置中心挂了怎么办（本地快照文件）？
- 敏感配置的加密存储与权限控制？

### 9. 设计一个抢红包系统

- 红包金额拆分算法（二倍均值法等）在什么时机执行？
- 并发抢红包的存储设计：抢与拆分怎么原子化（Redis Lua / DB 乐观锁 + 流水）？
- 红包领取记录的账务一致性：24 小时退回怎么实现？
- 明星发红包的瞬时热点怎么扛（异步化、排队）？

### 10. 设计一个代码发布/部署系统（类 PaaS）

- 发布流水线怎么建模？发布单状态机怎么设计？
- 灰度策略：按比例、按机器、按流量标记（泳道）怎么实现？
- 发布过程中服务健康检查、自动回滚的触发条件与实现？
- 多机房发布的顺序控制？配置与代码的发布顺序依赖怎么处理？

### 11. 设计一个实时大盘/实时统计系统（类双十一大屏）

- 数据链路：埋点 → 采集 → 计算 → 存储 → 展示，各环节选型？
- Flink/Spark Streaming 的窗口、水位线、乱序处理？
- 精确去重（UV）用什么：Bitmap/RoaringBitmap/HyperLogLog 的取舍？
- 实时与离线数据对不上怎么办（Lambda 架构 / Kappa 架构）？

### 12. 设计一个开放平台 API 网关

- 网关核心功能拆解：路由、鉴权、限流、熔断、协议转换、审计，插件化怎么设计？
- 鉴权体系：AppKey/Secret 签名、OAuth2、JWT 的选型？
- 网关自身怎么做到高可用、高性能（异步非阻塞、无状态）？
- 灰度路由、流量染色、请求副作用（重试导致重复）怎么防？
