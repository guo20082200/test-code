# database 文件夹说明文档

## 一、文件夹概览

`database/` 是一套**数据库面试题集**（主要面向中高级后端 / DBA / 架构岗位），覆盖 MySQL 与 PostgreSQL 两大主流数据库，从机制原理（存储引擎、事务锁、MVCC、日志体系）到运维实战（高可用、分库分表、VACUUM、备份恢复）均有涉及。全部为 Markdown 文档，另附一份同名 PDF。

| 文件 | 类型 | 主题 |
|---|---|---|
| 01-MySQL存储引擎与索引.md | 面试题 | MySQL 存储引擎、索引与查询优化 |
| 02-MySQL事务与锁.md | 面试题 | MySQL 事务、锁与隔离级别 |
| 03-MySQL架构高可用与优化.md | 面试题 | MySQL 架构、高可用与性能优化 |
| 04-PostgreSQL核心.md | 面试题 | PG 架构、MVCC 与索引 |
| 05-PostgreSQL进阶与运维.md | 面试题 | PG 的 VACUUM、复制、分区与运维 |
| 06-MySQL与PostgreSQL对比.md | 面试题 | MySQL 与 PG 对比与选型 |
| 07-MySQL运转全景.md | 面试题 | 以「一条 UPDATE 生命周期」串起 MySQL 全景 |
| 07-MySQL运转全景-参考答案.md | 参考答案 | 上述题目的要点框架 + 关键细节 + 权衡取舍 |
| MySQL运转全景 ——从磁盘上的文件，到一条 UPDATE 的完整生命.pdf | PDF | 「MySQL 运转全景」主题的 PDF 版（约 1.5 MB） |

## 二、内容组织

### 1. MySQL 主线（01、02、03、07）

- **01-MySQL存储引擎与索引.md**：InnoDB 三大特性（Buffer Pool / Change Buffer / AHI）、B+ 树与聚簇索引、索引失效场景、EXPLAIN 解读、慢 SQL 分析、分页与 JOIN 优化、数据类型设计。
- **02-MySQL事务与锁.md**：ACID 落到组件、MVCC / ReadView 推导、快照读 vs 当前读、锁类型全盘点（S/X、意向锁、记录/间隙/临键锁）、死锁定位与处置、隔离级别矩阵与选型。
- **03-MySQL架构高可用与优化.md**：redo/binlog/undo 日志体系与两阶段提交、主从复制与延迟治理、GTID、高可用方案（MHA/MGR）、备份恢复（XtraBackup）、分库分表与扩容迁移、参数调优与监控。
- **07-MySQL运转全景.md（含参考答案）**：全题核心，以一条 `UPDATE` 的完整旅程为主线，串起磁盘物理结构（表空间/区/页）、内存结构（Buffer Pool）、三套日志（redo/undo/binlog）、两阶段提交、崩溃恢复与 doublewrite、双 1 可靠性规划、观测诊断速查。**07 为唯一带参考答案的文件**，答案以「要点框架 + 关键细节 + 权衡取舍」形式给出。

### 2. PostgreSQL 主线（04、05）

- **04-PostgreSQL核心.md**：多进程模型、MVCC 的 xmin/xmax 实现（与 MySQL 原地更新 + undo 的本质差异、表膨胀根源）、WAL 与崩溃恢复、索引体系（B-Tree / GIN / GiST / BRIN / 部分索引）、执行计划解读、JSONB 与全文检索。
- **05-PostgreSQL进阶与运维.md**：VACUUM 与膨胀治理、XID 回卷、流复制与复制槽、Patroni 高可用、逻辑复制、分区表、权限模型与 RLS、扩展生态（pgvector 等）、参数调优与锁排查。

### 3. 横向对比（06）

- **06-MySQL与PostgreSQL对比.md**：进程 vs 线程模型、两种 MVCC 实现的连锁影响（膨胀/快照/幻读）、聚簇索引 vs 无聚簇索引、物理复制 vs 逻辑复制、JSON/全文检索能力、备份恢复对比，以及带权重评估矩阵的选型决策。

## 三、文件结构模式（通用模板）

每份面试题文档基本遵循同一模板：

1. **标题 + 适用岗位提示**：标注目标岗位（中高级后端 / DBA / 架构方向）与考察建议。
2. **按模块分章节**：每个模块下以「追问链 / 场景题 / 实战题」形式列题，强调「为什么」的机制理解与现场推演能力。
3. **附：评估要点**：以表格给出各维度权重（如索引 45%、锁机制 40%）及「入门 / 中级 / 高级 / 资深」的判定要点，用于面试打分。

## 四、使用建议

- 面试准备：按 MySQL → PG → 对比 的顺序阅读；「运转全景」作压轴综合题，结合参考答案检验机制理解。
- 实战导向：各文件中的场景题（死锁推演、主从延迟止损、膨胀处置、PITR 恢复演练等）建议结合个人运维案例作答。
- 组合关系：01–03 构成 MySQL 完整知识链；04–05 构成 PG 完整知识链；06 做交叉对比；07 是 MySQL 全貌的总复习题。
